# mle-razrabotka-v-ide

В коде описан класс DataFrameReporter. Цель класса - быстрый доступ к основной информации любого датафрейма, без необходимости выполнения команд вручную.

Описанный в нем метод show_report позволяет получить следующую информацию:

- количество столбцов;
- количество строк;
- количество дубликатов;
- доля дубликатов;
- количество пропусков;
- доля пропусков.

Для установки необходимого окружения и последуюющего запуска необходимо:

- убедится, что находитесь в изолированном окружении:
	выполнить which python/whoch python3
	если нет, активировать целевое окружение  - source имя окружения/bin/activate

- находясь в папке с requirements.txt выполнить pip install -r requirements.txt:
	флаг -r определяет - именя устанавливаемых библиотек прочитать из указанного текстового файла

- запустить файл main.py применив команду python3 main.py / python main.py:
	результат работы функции будет вывед в терминал
